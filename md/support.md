# Support

Part of the KLARA API documentation. Canonical page: https://developer.klara.ch/#support

## Support

Questions and problem reports: [support.klara.ch](https://support.klara.ch). When reporting an error, include the `uuid` from the error response and the steps to reproduce it, but never your API key or any credentials.

> **Note: What this documentation is, and what it is not**
>
> The KLARA API is provided as is, on the basis of this documentation. We do not offer guided implementation or code support for individual integrations.

Every release is recorded in the [changelog](https://developer.klara.ch/#changelog), including breaking changes.

KLARA is a product of ePost Service AG. Looking for the ePost Communication Platform APIs? Go to [developer.epost.ch](https://developer.epost.ch). Generated from the KLARA OpenAPI specification on 7 September 2026. Updated when a new API version is released.
